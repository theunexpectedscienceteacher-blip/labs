For Teachers

Everything you need to run these labs tomorrow: no accounts to set up, no rosters to upload and no student data to worry about.

How to run a lab in 4 steps

  1. Share the link to the lab (post it in your LMS or put it on the board). Students do not need to sign in.
  2. Students work through the tabs in order: overview and prediction, lab trials, data and graph, challenge, then analysis.
  3. Students compile and submit. The last tab builds a summary of their data and answers. They copy it into your assignment in Schoology, Canvas or Google Classroom, or print it.
  4. On shared Chromebooks, students press Clear my work from this device at the bottom of the page when they finish.

Class codes: labs with a class code box let you give each period a short code (for example P3). It prints at the top of the student's summary so you can sort submissions quickly. It is not stored anywhere.

Good to know

  • Work saves automatically in the student's browser, so they can finish another day on the same device.
  • Labs work on Chromebooks, laptops and tablets. A full-size screen is best for the simulations.
  • Most labs take one class period (about 45 minutes). Games and review take 15 to 30 minutes.
  • Each simulation is a scientific model. Models simplify the real world on purpose; the labs ask students to think about that.
